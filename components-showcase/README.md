# Frontend components showcase

A one-page field guide to frontend components, grouped into seven families
(Actions, Inputs, Navigation, Feedback, Data display, Layout, Overlays).
Each component has a one-line explanation and a live example.

Two ways to open it, both work by double-clicking (no server needed):

- `components-showcase-standalone.html`: one file with every style, script, font and image inlined. Copy it anywhere.
- `index.html`: the same page built from the source files next to it (`styles.css`, `components.css`, `kit.js`, `tokens/`, `assets/`). Keep the folder together.

Built with the Capgemini Invent design system.
